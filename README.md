# Budget Tracker

## Project Description

This project is a simple Budget Tracker website created using HTML and CSS. It allows users to enter their expenses and view sample expenses in a table.

## Features

* Expense form for entering expense details.
* Category dropdown with:

  * Food
  * Transport
  * Rent
  * Entertainment
  * Other
* Expense table with Name, Amount, Category, and Date columns.
* Sample expense data.
* Budgeting tips video embedded using an iframe.
* Logo displayed near the main heading.
* Collapsible "How to use this tracker" section.
* Hover effects on table rows.
* Focus styles for form inputs.
* Pointer cursor on the Add Expense button.
* CSS selectors including descendant, direct child, position pseudo-class, negation, and focus selectors.

## Technologies Used

* HTML5
* CSS3

## How to Use

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Enter an expense using the form.
4. Select a category from the dropdown.
5. Select the date.
6. Click the **Add Expense** button.

The button does not add expenses yet because JavaScript functionality will be added in a later lesson.
